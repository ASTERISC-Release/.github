We build computer systems that are:

- **Secure.** We strengthen privileged system software, such as operating systems and hypervisors, with new protection abstractions and fine-grained attack investigation.
- **Trusted.** We guarantee that computations stay confidential and intact even when the system software itself is controlled by someone untrusted, such as a cloud provider.
- **Reliable.** We develop efficient, automated techniques to test whether software and hardware execute correctly, which security and trust both depend on.

Our work spans confidential computing (SGX/TDX/SEV), system auditing and provenance, and kernel security.
